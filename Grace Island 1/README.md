# 恩典之島 Grace Island 交接說明

《恩典之島》是一款以基督教靈修為核心的 3D 網頁養成遊戲。玩家寫下靈修、感恩或生氣的事，每則紀錄都對應一隻動物，可以日後從紀錄找回牠。極地島嶼以《企鵝島》的氣氛為參考，動物以提供的 HTML 樣板為基礎，再為本遊戲加入造型、動畫和玩法。

## 如何開始

| 檔案 | 用途 |
| --- | --- |
| [index.html](index.html) | 直接用支援 WebGL 的瀏覽器開啟，即可試玩。遊戲以單一 HTML 交付，無須編譯。 |
| [水生動物預覽](grace-creatures/preview.html) | 單獨轉看本次合併的七種水生動物，試游姿和動作。 |
| [verify.cjs](verify.cjs) | 在此資料夾執行 `node verify.cjs`，跑本機模擬檢查。 |
| [DEPLOY.md](DEPLOY.md) | GitHub Pages 發布和 Supabase 共享群島設定。 |
| [supabase.sql](supabase.sql) | 建立或更新共享群島所用的資料表與權限。 |

電腦用左鍵平移、右鍵旋轉，右鍵可轉到水下，滾輪可縮放。手機在場景中上下滑可下潛或上浮，也可切換平移與旋轉，並用雙指捏合縮放。「回到島上」可回到預設視角。可以切換白天、黃昏和極光。

個人紀錄存在瀏覽器裡。移交程式可直接複製整個資料夾。如果接手者也要延續現有島嶼，請在原遊戲點「備份」，匯出 JSON，再於新位置匯入。備份含私人文字，應與程式分開交付。

## 暫時全解鎖試玩

正式版預設使用解鎖條件。新玩家預覽另用獨立存檔。
在 index.html 將 `GRACE_PREVIEW_UNLOCK_ALL` 改為 `true` 可開啟全解鎖試玩，改回 `false` 就會恢復正式門檻。試玩時儲存的紀錄和動物會保留，解鎖進度按實際儲存的紀錄計算。

## 已實作的玩法

**靈修。** 玩家可寫日期、標題、經文與心得。每篇新增靈修生成一隻已解鎖的動物，可點動物看日記，也能從日記定位牠。開局可選阿德利企鵝，之後每累積三篇依序解鎖海豹、皇帝企鵝、北極熊、跳岩企鵝、海豚、企鵝寶寶、鯨魚、虎鯨、白鯨和獨角鯨。累積第 3、8、15、30 篇時，主島分別擴張小山丘、草地、森林與天堂。每座約為初始主島的一半，以木橋相連，每座最多容納六位訪客，每座橋同時由一位動物通行。木橋已接到主島岸邊。

**企鵝造型。** 有牧師、戰士、天使、園丁與花冠禮服。靈修連續第二天起，每多一天可再解鎖一次。按實際儲存日計算，同日多篇只算一天。每次指定一隻企鵝與一款服裝，權利跟著那隻企鵝。新版沿用舊日記與已穿上的服裝。皇帝企鵝比最初版本縮小 20%，其餘企鵝縮小 10%。北極熊已調整眼睛位置與坐姿的四肢銜接。

**感恩。** 從「記感恩」獨立新增，每則生成一隻選定的魚。起初可選鯖魚，累積 10 則感恩後開放魟魚寶寶，20 則後開放鬼蝠魟。鯖魚在近岸結群，魟魚寶寶靠近海床，鬼蝠魟以寬鰭游動。可點魚或從「感恩紀錄」回訪、編輯原文，再選「去看牠」。感恩與靈修各自累計。

**生氣。** 從「記生氣」獨立新增。「有點生氣」對應黑鰭礁鯊，「非常生氣」對應雙髻鯊。儲存後魚種固定。玩家可回訪、編輯原文，並補寫「我現在怎麼看這件事？」目前寫過補寫後即可放生。放生會把鯊魚移出場景，從「已放生」仍可重讀、補寫、帶回島上或永久刪除。

**共享群島。** 已有 GitHub Pages 與 Supabase 的接線。設定後，訪客可以各自建立島主身分，查看鄰島、靈修動物與企鵝造型。私人紀錄留在本機。目前資料夾尚未填入正式 Supabase 專案設定。

## 後續規劃

| 項目 | 已討論的方向 |
| --- | --- |
| 主島海豹 | 海豹和北極熊已有主島岸灘活動區。海豹在岸上滑行和休息，後續可加入下水游泳再上岸的動作。 |
| 居民增加後擴島 | 第 21 隻企鵝時延伸出雪地半島，約 40 隻時再生成可由木橋往來的小島。之後可每多約 20 隻擴一區。這些是試玩用的設計門檻，目前已實作的擴建依靈修篇數觸發。 |
| 感恩回訪補寫 | 感恩已能重讀與編輯。可比照生氣紀錄新增獨立補寫，保留當時的原文和日後的想法，仍對應同一隻魚。 |
| 已放生的動物預覽 | 已放生清單目前能查看紀錄與魚種。後續可在清單內提供獨立 3D 預覽。 |
| 實機與部署驗證 | 用桌面與手機檢查游姿、點擊回訪、下潛和北極熊坐姿，再用兩個瀏覽器身分驗證正式群島。跨裝置認領原本的島可在之後加入正式帳號。 |

## 水生動物模型

虎鯨、白鯨、獨角鯨、魟魚寶寶、鬼蝠魟、黑鰭礁鯊與雙髻鯊已改用 [grace-creatures](grace-creatures/README.md) 內的模型。模型和尾鰭、胸鰭或盤緣的動作內嵌於單一 HTML；島內仍使用各自的巡游、紀錄和解鎖規則。預覽頁的手動操控與動作面板只在預覽頁提供。

## 接手驗收

1. 開啟網頁，試寫一篇靈修和一則感恩，確認各自生成動物。從紀錄定位動物，再點模型回到原文。
2. 建立一則生氣紀錄，補寫後放生。確認鯊魚離開海域、紀錄進入「已放生」，並試用「帶回島上」。
3. 匯出 JSON，在另一個測試環境還原，確認三類紀錄和放生狀態都能取回。現有匯入確認畫面顯示靈修和感恩數量，生氣紀錄同樣隨備份還原。
4. 執行 `node verify.cjs`。新版已通過這組模擬檢查，正式瀏覽器畫面與真實資料庫仍需實測。
